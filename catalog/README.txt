Jack in the Shop - Product Catalog (GitHub Pages)
================================================

WHAT'S IN HERE
  index.html          The catalog page (loads photos from photos.json)
  assets/             All 128 catalog photos (43 product lines)
  assets/photos.json  The list of products and photos the page reads
  photos.json         Same file, also at the root as a fallback
  README.txt          This file

HOW TO PUT IT ON GITHUB
  1. Copy index.html, assets/, and photos.json into Jack's
     jackintheshop.com GitHub repo (e.g. in a /catalog/ folder,
     or at the repo root if the catalog is the whole site).
  2. Commit and push. GitHub Pages rebuilds the site automatically.
  3. Open the page - it should show 43 product lines / 128 photos.

HOW JACK UPDATES IT LATER
  1. Upload a new JPG into assets/
  2. Add one line for it in assets/photos.json (use the private
     Catalog Editor page - do not edit it on the public site)
  3. Commit and push. The new photo appears automatically.

Do not add duplicate photos - 84 duplicates were already removed
from the Drive folder. Check the duplicate list first.
